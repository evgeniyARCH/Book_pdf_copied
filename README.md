# Что это?
Программа для создания копии электронной книги, которую нельзя скачать

# Разработчик
Коркин Евгений

# Важно
0. Необходимо прочитать данную инструкцию полностью перед запуском программы
1. Данный скрипт был разработан для работы на пк под управление Windows
! Автору неизвестно, как программа поведет себя на каком-либо дистрибутиве Linux или Mac OS
! Использование на мобильных устройствах (планшет/телефон) не подразумевалось
2. Проведены эксперименты на документах, которые открываются в браузере с помощью Adobe Acrobat Reader 
3. Данные, которые сейчас занесены в main.py, измерены экспериментально на экране с разрешением 1920x1080 пикселей

# Подготовка необходимой книги
1. Открыть нужную книгу в полноэкранном режиме (обычно кнопка F11)
2. Проверить, чтобы была выбрана "Вертикальная прокрутка"
3. Выбрать масштаб "По размеру страницы"
4. Проверить, что нажатия на стрелки вверх и вниз переключают страницы. 
! Если на этом этапе поменялся масштаб, то нужно повторить дейтсвие (3), после чего нажать на страницу книги и выполнить действие (4)
5. Стрелкой вверх дойти до 1-й страницы документа
! Это нужно, так как при пролистывании мышью сверху остается черная полоска на первой странце, чего при использовании клавиатуры не происходит
6. Выйти из полноэкранного режима (обычно кнопка F11)

# Сбор нужных параметров для программы
1. Пока не выполнили пункт (6) из "Подготовка необходимой книги", сделайте скриншот всего экрана и сохрани его в любую папку
2. Открой эту картинку в приложении Paint
3. Наведись на верхнюю левую точку страницы документа
4. Снизу в программе будут показаны координаты: первая - это left, вторая - up
5. Теперь переместись в нижнюю правую точку документа и выпиши координаты. Теперь первое число - right, второе - down

# Подготовка скрипта
0. Устанавливаем с помощью pip все зависимости (перечислены в requirements.txt)
1. Открываем папку как проект в среде для программирования (Visual Studio Code, PyCharm и т.д.)
2. Открываем файл main.py
3. Туда заносим все собранные значени и количество страниц книги
4. Запускаем скрипт. Теперь у вас есть 10 секунд, чтобы перейти в браузер, открыть книгу в полноэкранном режиме и сделать нажатие стрелками вниз и вверх (для калибровки)
